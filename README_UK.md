# COLD AI — скляне оновлення

Змінено лише код застосунку (`app/src/main/java/com/coldai/assistant/`). Gradle, Manifest і дозволи не чіпали.

## Файли
- `MainActivity.kt` — екран, команди, дзвінки/SMS із підтвердженням, налаштування, Gemini
- `Ui.kt` — фон-аврора, скляна кнопка мікрофона, звукова хвиля
- `VoiceEngine.kt` — розпізнавання: вибір мови, N-best, контроль паузи, автоповтор, сторожові таймери
- `Speaker.kt` — озвучення (мова за текстом, вибір голосу, швидкість)
- `CommandParser.kt` — розбір команд (укр + рос), слово «Колд»
- `Contacts.kt` — пошук контактів з урахуванням відмінків

## Збірка APK (GitHub Actions)
Як і раніше: завантажте вміст папки в репозиторій → Actions → Build COLD AI APK → Artifacts.

## Важливо
- Код НЕ компілювався в середовищі, де він писався (немає Android SDK). Перша збірка в CI може показати дрібні помилки — надішліть текст помилки, і я виправлю.
- Режим «Колд» (Налаштування → Режим «Колд») працює лише поки застосунок відкритий і екран увімкнений. У фоні мікрофон не використовується.
- SMS відкривається в застосунку повідомлень; надсилаєте ви самі.
- Розпізнавання іде через Google-службу пристрою. Для якіснішої української завантажте офлайн-мову: Налаштування Android → Google → Голосове введення.
